# Skip List Container

An STL-style templated Skip List container in C++20.

## Features
- Generic Skip List (`SkipList<T>`)
- Iterators (`begin()`, `end()`)
- Operators (`==`, `!=`)
- Unit tests using Google Test
- CI via GitHub Actions
