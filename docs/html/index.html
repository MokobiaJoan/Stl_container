Skip List Data Structure in C++

Introduction

This project implements a Skip List, a probabilistic data structure that supports fast search, insertion, and deletion operations in O(log n) average time complexity. It is an alternative to balanced binary search trees.

Features

  • Templated skip list implementation (e.g., SkipList<int>, SkipList<string>, etc.)
  • insert(), erase(), and find() methods
  • Support for equality comparison (== and !=)
  • Forward iterator support for range-based loops
  • Google Test-based unit testing
  • Written in modern C++ (C++20)

Example Usage

#include "skip_list.hpp"
#include <iostream>
int main() {
SkipList<int> list;
list.insert(5);
list.insert(10);
list.insert(7);
if (list.find(10)) {
std::cout << "Found 10" << std::endl;
}
list.erase(5);
for (int value : list) {
std::cout << value << " ";
}
return 0;
}
