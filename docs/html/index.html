Skip List (C++20)

📚 Introduction

This project is a modern, generic implementation of a Skip List data structure written in C++20.
It supports STL-style features and uses C++20 concepts (requires std::totally_ordered<T>) for strict type checking.

🚀 Features

  • Template-based skip list: SkipList<T>
  • STL-style forward iterator:
    • begin(), end() for range-based loops
  • Core container operations:
    • insert, erase, find
  • Container utilities:
    • size(), empty(), clear(), swap(), operator[]
  • Equality operators: ==, !=
  • Uses C++20 concepts: requires std::totally_ordered<T>
  • Fully unit tested using Google Test
  • Doxygen-compatible documentation

📎 Example

#include "skip_list.hpp"
#include <iostream>
int main() {
SkipList<int> list;
list.insert(10);
list.insert(20);
if (list.find(10)) {
std::cout << "Found 10!" << std::endl;
}
for (const auto& item : list) {
std::cout << item << " ";
}
std::cout << std::endl;
}
